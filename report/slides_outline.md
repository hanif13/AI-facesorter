# โครงสไลด์ Face Sorter

1. ปัญหา: รูปงานมีจำนวนมากและรูปหนึ่งมีหลายคน ผู้ร่วมงานหารูปตัวเองยาก
2. เป้าหมายและขอบเขต: จัดกลุ่มตามบุคคลในเครื่อง ตรวจแก้ได้ ส่งออกโดยเก็บต้นฉบับ
3. สาธิตผลิตภัณฑ์: เลือกโฟลเดอร์ → รอ → ตรวจและตั้งชื่อ → ส่งออก
4. ภาพรวมระบบ: รูป → SCRFD → จัดแนว → pretrained ArcFace R50 → embedding → DBSCAN / HDBSCAN → กลุ่ม
5. หลักการเปรียบเทียบ: เวกเตอร์ 512 มิติ, L2 normalization, cosine similarity; ArcFace เป็นวิธีฝึกของโมเดลสำเร็จรูป ไม่ได้ฝึกใหม่ในรุ่นนี้
6. การจัดกลุ่มและแก้ไข: density clustering, Unknown, noise rescue, รวม/แยกด้วยผู้ใช้
7. ผลรันจริง: จำนวนรูป/ใบหน้า/กลุ่มและเวลา จาก outputs/projects/day3_ready/summary.json และ day3_product/summary.json; จำนวนกลุ่มไม่ใช่จำนวนคนจริง
8. การทดสอบ: รูปหลายคนอยู่หลายโฟลเดอร์ ไม่มีซ้ำในโฟลเดอร์เดียว ต้นฉบับไม่เปลี่ยน และตรวจพื้นที่ก่อนส่งออก
9. ข้อจำกัดและผลที่ต้องตรวจ: หน้าเล็ก/เบลอ/หันข้าง คนหน้าคล้าย กลุ่มแตก ต้องมีคำตอบอ้างอิงเพื่ออ้างความแม่นยำ
10. สรุปสิ่งที่ได้และพัฒนาต่อ: ผลิตภัณฑ์ใช้งานได้ด้วยไลบรารีสำเร็จรูป งานต่อยอดคือค้นด้วยเซลฟีและปรับคุณภาพจากผลผู้ใช้
