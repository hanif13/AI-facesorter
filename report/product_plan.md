# แผนผลิตภัณฑ์ Face Sorter (ปรับวันที่ 3 ตุลาคม 2026)

ผู้ใช้แจ้งว่าได้สอบถามอาจารย์แล้ว อนุญาตใช้ไลบรารีและโมเดลสำเร็จรูป เน้นผลิตภัณฑ์ที่ใช้งานได้และอธิบายหลักการในรายงาน ข้อกำหนดการฝึก embedding จากศูนย์และ Gate 2 ก่อนฝึก 30 ชั่วโมงจึงไม่เป็นข้อบังคับของงานรุ่นปัจจุบัน ไม่ได้เริ่มฝึกยาว และไม่ลบข้อมูลหรือผลทดลองเก่า

## งานหลัก

1. ใช้ SCRFD ตรวจและจัดแนวใบหน้า ใช้ pretrained ArcFace R50 สร้าง embedding ผ่าน InsightFace/ONNX Runtime
2. ประมวลผลรูป day 3 ทั้ง 1,045 รูป สร้างชุดรูปสำหรับตรวจกลุ่มโดยไม่คัดลอกรูปทั้งชุดทันที
3. หน้าจอภาษาไทย เลือกโฟลเดอร์ แสดงความคืบหน้า ดูใบหน้าและรูปงาน ตั้งชื่อ รวม/แยกกลุ่ม ย้ายใบหน้า บันทึกการแก้ไขและย้อนครั้งล่าสุด
4. ส่งออกทุกคนหรือเฉพาะบุคคล คัดลอกต้นฉบับไปทุกโฟลเดอร์ที่เกี่ยวข้อง ตรวจพื้นที่ก่อนส่งออก ไม่เขียนทับผลเก่า
5. ทดสอบกรณีรูปหลายคน การแก้กลุ่ม การส่งออกและรูปต้นฉบับไม่เปลี่ยน ตรวจหน้าจอจริง
6. จัดทำคู่มือ รายงานภาษาไทย และโครงสไลด์ อธิบายหลักการและบทบาทของแต่ละไลบรารี ระบุ pretrained ให้ชัด ทุกตัวเลขต้องมาจากผลรันจริง

## ขั้นต่อไปก่อนส่งงาน

- ผู้ใช้ลองดูชุดรูปและตรวจกลุ่มผิด ตั้งชื่อบุคคลที่ต้องการ
- ใช้ตัวอย่างที่ตรวจยืนยันเองวัดผลการรวมผิด/แยกผิดและความครบถ้วนในการหารูป ห้ามเรียกจำนวนกลุ่มว่าจำนวนคนที่ยืนยัน หรืออ้าง accuracy โดยไม่มีคำตอบอ้างอิง
- เติมภาพหน้าจอและตัวอย่างปัญหาที่ตรวจยืนยันลงรายงาน เตรียมสาธิตเลือกโฟลเดอร์ → ตรวจกลุ่ม → ส่งออก
- หากต้องการปรับปรุงคุณภาพ ทดลองค่า clustering บนข้อมูลที่ตรวจเองก่อน ข้อมูลประเมินสุดท้ายต้องแยกจากข้อมูลที่ใช้เลือกค่า
- งานเสริมเมื่อเวลาพอ: ค้นหาด้วยเซลฟี และบรรจุแอปให้ติดตั้งง่าย ไม่เป็นข้อบังคับรุ่นแรก

ไม่จำเป็นต้องใช้ CASIA หรือ LFW สำหรับเปิดโปรแกรม แต่ยังเก็บไฟล์เหล่านี้และ checkpoint ทดลองไว้ การลบข้อมูลเพื่อคืนพื้นที่ต้องเป็นคำขอแยกจากผู้ใช้
