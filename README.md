# Face Sorter — จัดรูปตามบุคคล

โปรแกรมค้นหาใบหน้าและจัดรูปเป็นกลุ่มบุคคลอัตโนมัติ ผู้ใช้ตรวจแก้กลุ่ม ตั้งชื่อ แล้วดาวน์โหลดรูปเป็น ZIP ที่แยกโฟลเดอร์ตามบุคคลได้ ใช้โมเดลสำเร็จรูป ไม่ต้องเทรนเอง

สำหรับรันบน **Mac ของตัวเอง** ผ่านเว็บเบราว์เซอร์บนเครื่องเดียวกัน รูปประมวลผลในเครื่องและไม่ถูกอัปโหลดไปเซิร์ฟเวอร์ รูปต้นฉบับยังอยู่ที่เดิม

## 1. เตรียมเครื่อง

ติดตั้ง **Git และ Python 3.11** ให้เรียบร้อย สำหรับปุ่มเลือกโฟลเดอร์บน Mac ใช้ Command Line Tools ติดตั้งครั้งเดียวหากยังไม่มี:

```sh
xcode-select --install
```

## 2. Clone และติดตั้ง

เปิด Terminal แล้วรันทีละบรรทัด:

```sh
git clone https://github.com/hanif13/AI-facesorter.git
cd AI-facesorter
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip setuptools wheel cython cmake numpy
python -m pip install --no-build-isolation insightface==0.7.3
python -m pip install -r requirements.txt
```

ต้องเชื่อมต่ออินเทอร์เน็ตตอนติดตั้ง และตอนประมวลผลครั้งแรกเพื่อดาวน์โหลดโมเดลอัตโนมัติ

## 3. เปิดโปรแกรม

รันจากโฟลเดอร์ `AI-facesorter` ที่ clone มา:

```sh
.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1
```

เปิด **http://127.0.0.1:8501** และเปิด Terminal ทิ้งไว้ระหว่างใช้งาน

ครั้งถัดไปให้เข้าโฟลเดอร์โปรแกรมแล้วรันคำสั่งเดิม หรือดับเบิลคลิก `เปิดโปรแกรม.command` บน Mac หลังติดตั้งเสร็จแล้ว

> ถ้าขึ้น `no such file or directory: .venv/bin/python` ให้ตรวจว่าเข้าโฟลเดอร์ที่มี `app.py` และสร้าง `.venv` แล้ว สำหรับเครื่องเดิมของผู้พัฒนา โฟลเดอร์นี้คือ `/Users/hanif/AI TRANNING/face-sorter`

## 4. ใช้งาน

1. เลือก **＋ สร้างชุดรูปใหม่** → กด **เลือกโฟลเดอร์รูป** → ตั้งชื่อชุดรูป
2. กด **เริ่มค้นหาและจัดกลุ่มใบหน้า** แล้วรอจนเสร็จ ใช้ค่าตัวเลือกขั้นสูงเดิมได้
3. เปิดแท็บ **ตรวจกลุ่มบุคคล** เพื่อตั้งชื่อ รวมกลุ่ม หรือย้ายใบหน้าที่จัดผิด การแก้ไขบันทึกให้อัตโนมัติ
4. เปิดแท็บ **ดาวน์โหลดรูป** → เลือกทุกคนหรือเฉพาะบางคน → กด **เตรียมไฟล์ ZIP สำหรับดาวน์โหลด** → กด **ดาวน์โหลดโฟลเดอร์รูป (.zip)**
5. แตก ZIP เพื่อใช้โฟลเดอร์รูปของแต่ละบุคคล รูปที่มีหลายคนจะอยู่ในทุกโฟลเดอร์ที่เกี่ยวข้อง

กลับมาทำต่อได้โดยเลือกชื่อชุดรูปเดิมจากเมนูด้านซ้าย ควรตรวจกลุ่มก่อนดาวน์โหลด เพราะระบบอาจจัดใบหน้าผิด และควรมีพื้นที่ว่างสำหรับ ZIP ทั้งที่โปรแกรมเตรียมไว้และที่ดาวน์โหลด

## 5. ปิดโปรแกรม

กลับไป Terminal แล้วกด **Control + C**

ข้อมูลชุดรูปเก็บใน `outputs/projects/` และโมเดลเก็บใน `outputs/models/` ห้ามย้ายหรือลบรูปต้นฉบับระหว่างที่ยังใช้ชุดรูปนั้นอยู่ รายละเอียดหลักการทำงานอยู่ใน [รายงาน](report/report.md)
